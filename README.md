# 方块游乐场 · Block Playground

一个本地运行的三游戏合集：**叠砖块**、**2048** 与 **扫雷**。

项目已从单文件 `2048.html` 重构为多文件结构，使用原生 Web 技术、经典脚本加载，因此无需安装、联网或启动本地服务器。

## 快速开始

- 双击桌面快捷方式 **方块游乐场**：以 Edge 应用窗口 **默认全屏** 打开。
- 也可以直接打开 [`index.html`](index.html)。
- 或运行 [`启动游戏.cmd`](启动游戏.cmd)，效果与快捷方式相同。

在全屏窗口中可随时按 **Esc / F11** 退出全屏；右上角也提供全屏切换按钮。

## 操作

### 2048

- **W / A / S / D**：上 / 左 / 下 / 右移动
- **方向键**：同样可用
- **Ctrl + Z / Cmd + Z**：撤销上一步
- 合成 2048 后可以继续挑战更高分

### 叠砖块

- **空格键** 或 **落下** 按钮：放下正在移动的砖块
- 稳定叠满 **60 层** 即胜利
- 整局最多允许 10 块砖落空；重心失衡会导致高塔坍塌
- 隐藏操作：同时按住 **C + H** 切换上帝模式，砖块宽度从 30% 变为 60%

### 扫雷

- **左键**：翻开安全格
- **右键**：插旗 / 取消插旗
- **M**：切换标记模式，方便触屏操作
- 三档难度：初级 9×9、中级 12×12、高级 16×16
- 首次左键必定安全；清空所有非雷格即胜利

### 全局

- 右上角按钮：**分享**、**全屏**、**音效**、**深绿 / 纯黑主题**
- 每款游戏的右上角「玩法」可随时重新打开对应教程
- 主题、静音、最高分、扫雷最快纪录与教程阅读状态都会自动保存

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架、无外部资源、无构建步骤。
- 采用经典脚本按顺序加载，避免 `file://` 下 ES Module 的跨域限制，保证双击直接可用。
- 桌面快捷方式通过 Edge 的独立配置目录启动，确保每次打开都能直接进入全屏应用窗口。
- 音效全部由 Web Audio API 实时合成：2048 合并为合成铃音，叠砖块落地为低频撞击声。
- 扫雷使用原生 DOM 网格实现；支持首击安全、空区自动展开、右键插旗、触屏标记模式、计时和三档难度。

## 兼容性

建议使用最新版 Microsoft Edge 或 Chrome。界面支持桌面与手机尺寸；桌面快捷方式使用 Edge 全屏应用窗口，以获得接近独立应用的体验。
